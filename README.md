# VocalPrep

A singing-practice app for the iPad: https://l-sial.github.io/vocalprep/
(open it in Safari › Share › **Add to Home Screen**).

1. **Capture** — open a lesson recording (Dropbox, Files), put markers on the exercises, select regions and add them
   to the **Repository**. Then remove the full recording; the regions stay.
2. **Practise** — drag regions from the Repository into today's list. Each region has a small waveform and one note
   you write. Earlier days show what you used. A pitch keyboard plays a note and its major scale to the fifth and back.

Export: regions as WAV files and notes as text, through the iPad share sheet (Notes, Files…).

## Changing the app from the iPad
1. Claude app › menu (☰) › **Code** (or claude.ai/code in Safari).
2. Choose the repository **L-SIAL/vocalprep**, branch **main**.
3. Type the change you want. Claude makes the next version and a pull request.
4. On GitHub: **Merge pull request** › **Confirm merge**.
5. Wait about 2 minutes, close the app fully, open it again while online. The version bottom left goes up by one.
